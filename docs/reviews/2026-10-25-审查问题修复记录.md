# AudioBule 审查问题修复记录

日期：2026-10-25。

本轮针对 [全面代码审查报告](2026-10-25-全面代码审查.md) 的 R1—R8 完成代码修改。原审查报告保留作为修改前快照；本记录描述当前实现和本轮实际验证。

## 修复内容与验收状态

| 问题 | 修改 | 本轮状态 |
| --- | --- | --- |
| R1 外部回调与对象析构竞争 | 新增 `CallbackGate`，回调先取得执行凭据；Manager、Provider 在销毁前关闭入口并等待已进入的回调，已复制回调只接触仍然存活的共享入口。WinRT 适配器保存、撤销事件令牌，关闭在状态锁外执行。 | Manager/Provider 的复制后迟到回调、在途回调析构等待测试通过 |
| R2 刷新丢失底层连接 | `Refresh()` 返回是否成功；枚举失败保留快照，App 显示刷新失败且不触发启动重连。成功移除已连接设备时关闭 Provider 会话；清理失败保留可操作记录。刷新事件在状态锁及刷新锁之外发布。 | 保留快照、移除关闭、清理失败恢复、刷新事件重入测试通过 |
| R3 旧关闭事件污染重连 | Manager 为连接请求分配进程内唯一代次并传入 Provider；关闭通知同时携带设备 ID 和代次。Provider 核对当前记录身份，Manager 拒绝旧代次事件；断开清理期间禁止同设备重试。 | 旧关闭通知及已复制旧会话回调不会覆盖重连的测试通过 |
| R4 打开前缺少监听 | 增加 `IAudioPlaybackSession` 平台接缝；生产会话在 Start/Open 前安装关闭监听。打开完成时同时核对会话实际状态、关闭标记及当前记录。失败路径退订并关闭会话。 | 打开期间关闭、没有事件但状态已经关闭的测试通过；真实蓝牙仍需验收 |
| R5 托盘失败后服务被销毁 | 将消息线程就绪与 Shell 图标登记分离；首次登记失败保留定时重试，并向主窗口上报实际可用性。图标丢失时保留可访问的窗口入口。增加仅冒烟模式启用的首次登记失败注入，以及只读登记状态查询。 | 线程与窗口创建通过；本机 Shell 实际登记仍失败，恢复验收未通过 |
| R5 运行时临时图标依赖 | 从嵌入 ICO 的匹配尺寸帧直接创建图标，验证目录、长度及边界；移除运行期临时文件写入，保留品牌、两种任务栏主题和连接徽标。 | 原有 9 项图标测试通过；不可用 TMP/TEMP 下也通过 |
| R6 筛选没有选择语义 | 使用同组原生 `RadioButton`，通过 Checked 事件同步筛选，保持互斥选择和现有指示；添加稳定自动化 ID，以及 UI Automation 选择断言。 | 两种架构编译通过；完整原生脚本在托盘入口失败，尚未运行到选择断言 |
| R7 成功信息显示为错误 | `SetStatus` / `SetStatusKey` 显式接收 `InfoBarSeverity`；诊断完整导出使用 Success，部分导出使用 Warning，失败使用 Error。沿用两种语言已有资源键。 | 两种架构编译通过；真实导出与视觉验收未完成 |
| R8 非相邻设备去重失败 | 保持首次出现顺序，先过滤空值和所有重复项，再限制 32 条。增加固定旧配置输入及保存后读回两种回归。 | 固定输入回归通过；保存后读回测试受本机临时目录写入拒绝影响 |

图标加载使用 Windows 的内存图像资源接口，资源格式及调用依据见[微软图标格式说明](https://devblogs.microsoft.com/oldnewthing/20231025-00/?p=108925)。没有修改原始品牌素材、资源编号或第三方依赖。

原生冒烟使用实际 x64 构建，并启用 `-TestTrayRecovery -TestDiagnosticPicker`。已通过 5 项前置检查：启动、托盘线程、目标进程消息窗口、主窗口与快速面板创建，以及主窗口大小品牌图标。随后“首次登记失败后自动恢复托盘登记”失败；服务只读状态也报告 Shell 登记结果为 false，排除了仅仅拿不到图标矩形这一解释。**当前运行上下文中 Shell 登记失败的最终原因尚未确认，不能将 R5 运行验收记为通过。** 本轮没有取得有效 UI 截图，也没有运行到筛选、语言、主题、导出、键盘和高 DPI 的完整验收。
